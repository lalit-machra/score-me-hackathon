## 5. Duplicate request

Submitting the same payload again returns the original decision (`duplicate: true`, same request id `true`). No stage runs again and the dependency is not called; the replay is logged as a system event visible in `explain`:

```json

  {
    "type": "DUPLICATE_REQUEST",
    "requestId": "4545fb76-fdd5-4eab-8153-2c8854001a5d",
    "idempotencyKey": "f220a42cec397f308852882e4a32c8a43c49cb93988be01b395d433199bae8d8"
  }
]
```
